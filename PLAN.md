# «Что на ужин?» — Android 1.0

Приложение для Android с русским и английским интерфейсом, встроенным каталогом и локальным подбором по продуктам и времени. Python готовит каталог на ПК разработчика. На телефоне читается упакованная SQLite, а ИИ работает при подготовке данных.

| Этап | Результат | Проверка |
| --- | --- | --- |
| 1. Схема и исходные рецепты | Двуязычная SQLite с 11 проверяемыми стартовыми рецептами | ID, состав и шаги сверены с исходным каталогом |
| 2. Пилот источников | Снимок 150 страниц Wikibooks с точными ревизиями | Отчёт по составу, шагам, времени и порциям |
| 3. Подготовка данных | Офлайн-сборщик Python для нормализации, дедупликации и учёта источников | Воспроизводимая SQLite, манифест и причины отклонений |
| 4. Переводы и восстановление | Двуязычный каталог, группы вариантов и отдельно хранимые дополнения | Структура, количества и язык проверяются. Источник и предположения модели различаются |
| 5. Нативный клиент | Android-приложение с подбором, просмотром каталога и переключением языка | Карточки и варианты читаются из локального файла |
| 6. Подготовка выпуска | Версионированный Android-каталог и готовый проект | Сверка источников и отбора записей, проверка запуска без сети |
| 7. Сборка и приёмка | Подписанный APK, контрольная сумма и результаты тестирования Android | Чистая установка, первый запуск без сети, поиск, порции и переключение языка |

Ориентир по объёму — 1 000–3 000 пригодных рецептов. Размер исходной выборки, покрытие перевода и фактическое число рецептов в APK учитываются отдельно. Рецепты с отсутствующими данными по времени или составу могут быть доступны в каталоге, а строгий подбор использует только записи с известными параметрами. Неподтверждённые дополнения сохраняются как черновики для проверки.
